Terms governing use of AAD · GitHub Actions Reporting.

1. Purpose

AAD · GitHub Actions Reporting is an operator-facing reporting utility that reads selected reporting artifacts from Google Drive, materializes reporting data into Google Sheets, and can maintain an Apps Script refresh trigger.

2. Authorized use

Use is limited to authorized operators and accounts with legitimate access to the Google Drive and Google Sheets resources involved in the reporting workflow. Users must not use the utility to access data they are not authorized to access.

3. Google services

The utility depends on Google Apps Script, Google Drive, and Google Sheets. Availability may be affected by Google service availability, OAuth authorization status, account policy, or API changes.

4. Data and privacy

Google user data is handled as described in the Privacy Policy. The utility's use of information received from Google APIs is intended to comply with the Google API Services User Data Policy, including Limited Use requirements.

5. No warranty

The utility is provided for the described reporting purpose on an as-available basis. Reporting outputs should be validated before they are relied upon for operational decisions.
